⚠ Google Drive indisponível neste ambiente
O Google OAuth não funciona quando o sistema é aberto diretamente pelo arquivo HTML (protocolo file://). Execute o sistema através de um servidor local.
  • VS Code — instale a extensão Live Server, clique com o botão direito no arquivo HTML e selecione "Open with Live Server". O sistema abrirá em http://127.0.0.1:5500
  • Python — abra o terminal na pasta do arquivo e execute python -m http.server 5500, depois acesse http://localhost:5500
  • Node.js — execute npx serve . e acesse o endereço exibido no terminal
Todas as outras funcionalidades (Dashboard, CSV, IndexedDB) continuam disponíveis normalmente.
